# Projet : Location de voitures (avec ou sans chauffeur) — Algérie

Chantier démarré le 2026-10-17. Point de départ : zéro.
Le nom de l'entreprise n'est pas encore choisi. En attendant, le projet s'appelle simplement « location-auto ».

## Structure

- `equipe/` : l'équipe d'agents. Un dossier par agent, avec son rôle (`ROLE.md`) et son état vivant (`etat.json`).
- `bord/` : le tableau de bord qui lit les états et montre la progression.
- `decisions/` : une fiche par décision prise (nom, cible, couleurs...). C'est la mémoire du projet.
- `JOURNAL.md` : le journal chronologique, une ligne par avancée.

## Règle d'or
Rien ne se dessine avant que le Stratège (Nadir) ait un état « validé ».
